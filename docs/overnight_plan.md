# แผนงานยาว (ทำเองต่อเนื่องจนหมดลิมิต ไม่ต้องรอตอบ)

อ้างอิงเกมยุคนี้: Pokémon Scarlet/Violet, Genshin Impact, Honkai: Star Rail, Palworld, Stardew Valley
กติกา: เล่นบนคอมเป็นหลัก ไม่ต้องคำนึงถึงโทรศัพท์, เซฟเก่าต้องเปิดได้ (ผ่าน `G.sanitizeSave`), ไม่มีกาชา/เติมเงิน, ไม่ทำระบบตราคุมความเชื่อฟัง,
คนจริงเขียนด้วยความเคารพ, ภาษาไทยทั้งหมด, ไม่ปรับสมดุลเรื่องหลักโดยไม่จำลองก่อน
ทุกชิ้นจบด้วย: build + test_battle + simulate + Playwright → commit → push → อัป artifact

## ระดับ S
1. ความสวยงามทั้งเกม: ภาพคม + มินิแมพภาพจริง ✅ / ป่าเป็นผืน หลังคาชายคา ดอกบัว หญ้า หิ่งห้อย แมลงปอ ผีเสื้อ
2. ผีสีพิเศษ (shiny) 1/200 ประกายตอนออก ดาวในสมุดบันทึก
3. ไอคอนไอเท็มทุกชิ้น + กรอบความหายาก + flavor text + ป้ายใหม่ + ป๊อปอัปได้ของมีรูป
4. ต่อสู้: ตัวเลขดาเมจ หลอดเลือดมีแถบตาม หน้าสรุปหลังชนะ
5. ความผูกพัน: ค่าความสนิท รอด 1 HP บทพูดพิเศษ หัวใจในหน้าทีม

## ระดับ S+ ความสะดวก (ทำต่อจากหมวดความสวยงามทันที)
- สู้ผีอ่อนแบบรวบรัด เมื่อเลเวลห่างมาก ชนะทันทีได้ EXP
- แสดง % โอกาสจับสำเร็จ
- ขายของในร้าน
- ประวัติบทสนทนา
- ฟื้นทีมด่วน (ใช้ยาคุ้มที่สุดอัตโนมัติ)
- วิ่งเป็นค่าเริ่มต้น
- แถบเลื่อนระดับเสียง เพลง/เสียงประกอบ
- เมนูจำตำแหน่งล่าสุด
- หยุดเวลาในเกมเมื่อสลับแท็บ
- จอยเกม + เปลี่ยนปุ่ม
- (ท้ายสุด) คลิกเมาส์บนแมพแล้วเดินไปเอง
- ตัวอักษรใหญ่ / โหมดสีสำหรับตาบอดสี

## ระดับ S++ ระบบโปเกมอนที่ยังขาด (รีเสิร์ชเทียบทุกภาค)
- ผีวิวัฒนาการ (ร่างที่สองของผีหลัก)
- ผีสีพิเศษ + จับต่อเนื่องเพิ่มโอกาส
- นิสัย (nature) +10%/-10%
- ความสามารถติดตัวของผีทุกตัว
- ของซ่อนบนแมพ
- ผีระบาด (mass outbreak)
- สมุดบันทึกบอกที่อยู่/เวลา/ความหายาก
- ฝากเลี้ยงที่วัด
- จักรยาน
- ตารางธาตุ
- ท่าไม้ตาย (เกจ 1 ครั้งต่อการต่อสู้)
- สภาพอากาศสนามเพิ่ม, ของถือเพิ่ม

## ระดับ A
6. ความสามารถติดตัวของผีทุกตัว
7. หลังจบเกม: ท้ายิมรอบสอง + หอท้าสู้ต่อเนื่องที่สนามอีสปอร์ต
8. ความสำเร็จ ~30 (ไม่มีภารกิจรายวัน: เกมออฟไลน์)
9. ทำอาหารอีสาน (ส้มตำ ลาบ ไก่ย่าง) บัฟระหว่างเดินทาง
10. ปฏิทินเทศกาล (ลอยกระทง สงกรานต์ บุญบั้งไฟ) ผี/ของพิเศษตามเทศกาล

14. สรุป "เรื่องที่ผ่านมา" ตอนโหลดเซฟ
