# แผนงานทั้งคืน (ทำเองต่อเนื่อง ไม่ต้องรอตอบ)

อ้างอิงสิ่งที่เกมยุคนี้ทำกันจนเป็นมาตรฐาน: Pokémon Scarlet/Violet, Genshin Impact, Honkai: Star Rail, Palworld, Stardew Valley
หลักการ: ทำของที่ผู้เล่นเห็น/รู้สึกได้ทันทีก่อน, ไม่ทำให้เซฟเก่าพัง (ผ่าน `G.sanitizeSave`), ไม่มีกาชา/เติมเงิน,
ไม่ทำระบบตราคุมความเชื่อฟัง, ตัวละครจากคนจริงเขียนด้วยความเคารพ, ทุกข้อความเป็นภาษาไทย

ทุกหมวดจบด้วย: build + test_battle + simulate + Playwright ถ่ายภาพ/เล่นจริง → commit → push → อัป artifact

## หมวด 1: ความสวยงามทั้งเกม (Stardew / Pokémon HD-2D)
1. ภาพคมทุกขนาดจอ (ขยายจำนวนเต็มแล้วย่อเนียน) + มินิแมพ/แผนที่ใหญ่เป็นภาพแมพจริง ลูกศรบอกทิศ ดาวเป้าหมาย  ✅
2. บ้าน: ชายคายื่น สันหลังคา ขอบจั่ว เงาใต้ชายคาลงผนัง ด้านแดด/ด้านเงา
3. ต้นไม้: ป่าเป็นผืนพุ่มต่อกัน (ไม่เป็นลูกบอลเรียงตาราง) ขอบเข้ม ไฮไลต์ใบ หลายพันธุ์ ใบไหว
4. น้ำ/บัว: ใบบัวมีรอยแหว่ง ดอกตูม/บาน/หุบกลางคืน สีชมพู-ขาว ระลอกน้ำ น้ำลึกตรงกลางเข้มกว่า
5. พื้น: หญ้าหลายโทน กอหญ้า ก้อนหิน ดอกไม้จิ๋ว
6. แสง: หิ่งห้อยกลางคืน (ทุ่ง ดอนปู่ตา ริมพอง) แมลงปอกลางวัน ไอแดดยามเช้า

## หมวด 2: ไอคอนไอเท็มและกระเป๋า (Genshin / Star Rail)
1. ไอเท็มทุกชิ้นมีไอคอนวาดเฉพาะ 16×16 (ตรวจทุกชิ้นที่ยังใช้ไอคอนรวม)
2. ระดับความหายาก 4 ขั้นตามราคา/ชนิด: ธรรมดา (เทา) · ดี (เขียว) · หายาก (ฟ้า) · ล้ำค่า (ม่วง) · ของสำคัญ (ทอง) กรอบสีในกระเป๋า
3. คำบรรยายสั้นแบบเกมจริง: บรรทัดผล + บรรทัดเกร็ดเล็กๆ (flavor text)
4. ป้าย "ใหม่!" บนของที่เพิ่งได้ + เรียงตามชนิด/ความหายาก
5. ป๊อปอัปได้ของแบบมีไอคอน (แทนข้อความล้วน)

## หมวด 3: ความมันตอนต่อสู้ (Pokémon SV / Star Rail)
1. ตัวเลขดาเมจเด้งบนตัว (สีตามได้ผลดี/ไม่ค่อยได้ผล/คริ)
2. หลอดเลือดลดแบบมีแถบตามหลัง (ghost bar)
3. หน้าสรุปหลังชนะ: EXP ที่แต่ละคนได้ เลเวลอัป เงิน ของที่ได้
4. แจ้งเตือนแพ้ทาง/ชนะทางตอนเลือกท่าให้ชัดขึ้น

## หมวด 4: แบ็กสตอรี่และโลก (Honkai Archive / Genshin Character Stories)
1. สมุดตัวละคร: โปรไฟล์ เด็ก 4 คน หัวหน้ายิม บอส คนสำคัญ ปลดล็อกทีละบทตามเนื้อเรื่อง (เรื่องเล่า 3 ตอนต่อคน)
2. สมุดบันทึกผี: เพิ่มตำนานพื้นบ้านอีสานของผีแต่ละตัว (ปลดล็อกเมื่อจับได้)
3. บันทึกสถานที่: เรื่องเล่าของแต่ละแมพ ปลดล็อกเมื่อไปถึง

## หมวด 5: บทพูดมีชีวิต (Stardew / Pokémon)
1. NPC พูดเปลี่ยนตามความคืบหน้าเรื่อง (ก่อน/หลังชนะยิมแต่ละด่าน) และตามช่วงเวลา
2. เด็กในแก๊งคุยกันเองตอนเข้าแมพใหม่ครั้งแรก (party banter)
3. คุยกับเพื่อนที่เดินตามได้ (หันหน้าเข้าหาแล้วกด Z) ประโยคตามแมพ/เวลา/เลือด
4. ตรวจคำผิด ชื่อเรียกให้ตรงกันทั้งเกม

## หมวด 6: ระบบเล่นต่อหลังจบ (Genshin Commission / Achievements)
1. ความสำเร็จ (Achievements) ~30 รายการ พร้อมรางวัลเล็กๆ และหน้าสรุป
2. ภารกิจรายวัน 3 อัน/วันในเกม (สุ่มจากรายการ: ชนะผี 5 ตัว ตกปลา ใช้ท่าธาตุน้ำ ฯลฯ)
3. หน้า "มีอะไรใหม่" (patch notes) ในเมนู บอกของที่เพิ่มคืนนี้
