# แก๊งเด็กบ้านนา (บทที่ 2)

เกมต่อสู้ผลัดตาสไตล์เกมจับมอนสเตอร์ยุค GBA ฉากหมู่บ้านอีสาน เด็ก 4 คนลงสู้กับผีสาง และชวนผีเข้าแก๊งด้วยข้าวเหนียว

## เล่นยังไง

- **ง่ายสุด:** ดับเบิลคลิก `index.html` (หรือ `dist/kaeng-dek-ban-na.html` ไฟล์เดียวจบ) เปิดในเบราว์เซอร์ได้เลย ไม่ต้องใช้อินเทอร์เน็ต
- **เป็นโปรแกรม:** `pip install pywebview` แล้ว `python tools/run_desktop.py` (วิธีทำ .exe อยู่หัวไฟล์นั้น)

| ปุ่ม | หน้าที่ |
| --- | --- |
| ลูกศร / WASD | เดิน · เลื่อนตัวเลือก |
| Z หรือ Space | คุย · ตกลง |

| Enter | เมนูหลัก (ทีม กระเป๋า สมุดบันทึก ตรา บันทึก 3 ช่อง ตั้งค่า) |

มือถือมีปุ่มบนจอให้อัตโนมัติ

## มีอะไรในเวอร์ชันนี้

**บทที่ 1** บ้านโนนสะอาด → เลือกคู่หู 1 ใน 4 → สู้โจ้แก๊งบ้านเหนือ → ลงทุ่งนา (ผีสาง 6 ชนิด กลางวัน/กลางคืนเจอต่างกัน) → โจ้ดักรอบสอง → บอสคางคกเจ้าหนอง → เพื่อนคนที่ 2 เข้าแก๊ง → ตลาดนัดตำบล → เข้าร้านราเมง → ยิม 1 พี่ออสซี่

**บทที่ 2** กลับหมู่บ้านจุดบุญบั้งไฟ เพื่อนคนที่ 3 เข้าแก๊ง → นั่งสองแถวไปมหาวิทยาลัยขอนแก่น คณะวิศวะ → ชวนน้องวิศวะ 6 สาขา (เครื่องกล โยธา ไฟฟ้า เคมี สิ่งแวดล้อม อุตสาหการ) รวม 48 คน ชื่อและหน้าตาไม่ซ้ำ เสื้อช็อปสีและตราต่างกันตามสาขา → อุ๋งอิ๋งสาวเคมีในห้องแล็บ → พี่ว้ากสองคนหน้าโรงช็อป → ในโรงช็อปไฟดับ: พื้นน้ำมันลื่น สายพาน ปริศนาสับคัตเอาต์ → ยิม 2 พี่เฟรนด์ (เครื่องกล เสื้อช็อปดำ) → ได้ตราเฟือง สะพานข้ามลำน้ำพองเปิด

ระบบที่ใช้ได้แล้ว: ต่อสู้ครบ (ธาตุ 5 ชนิด สถานะ บัฟ คริติคอล ความสามารถติดตัวของเด็ก AI 3 ระดับ) EXP/เลเวล/เรียนท่า เด็กเติบโตเปลี่ยนชุดที่ Lv 16 และ 32 ชวนผีด้วยข้าวเหนียว ชวนน้องวิศวะด้วยคูปองหมูกระทะ ทีม 6 คน + คลังแก๊งกรองตามประเภท (เถียงนาตาสี / คอมหอพัก) เลือกใครก็ได้ให้เดินตาม (คนที่เดินตามลงสู้ก่อน) ตั้งชื่อเล่น ของถือ ท่าลับรางวัลยิม ทุกตึกเดินเข้าได้ ร้านค้า (รวมน้ำปั่นร้านอิงอิง) รักษา เทรนเนอร์มองเห็นแล้วท้าสู้ เวลากลางวัน-กลางคืน (เสาไฟติดตอนค่ำ) ภาพเดิน 4 ทิศ เซฟ 3 ช่อง + สำรอง/นำเข้าเป็นไฟล์ เสียงและเพลงสังเคราะห์

## โครงสร้าง

```
index.html          หน้าเกม
css/style.css       หน้าตาเมนู (แผงผ้าคราม ขอบผ้าขาวม้า)
js/data.js          ข้อมูลเกม — สร้างอัตโนมัติ ห้ามแก้ตรง
js/formulas.js      สูตรสเตตัส ดาเมจ EXP การชวนผี
js/battle.js        ตรรกะต่อสู้ล้วน (ทดสอบได้โดยไม่มีหน้าจอ)
js/battleui.js      หน้าจอต่อสู้
js/world.js         แผนที่ การเดิน การเจอผี เวลา
js/story.js         บทพูดและเหตุการณ์ทั้งหมด
js/sprites.js       พิกเซลอาร์ต (เขียนเป็นตัวอักษร 16×16)
js/ui.js            กล่องข้อความ เมนู ร้านค้า
js/audio.js         เสียงและเพลง
data_src/           ข้อมูลที่แก้เอง: species.csv moves.csv items.csv types.csv encounters.csv eng_names.csv
                    แผนที่ *.txt (ข้างนอก village field market kku และในตึก) และ world.json (NPC ประตู ป้าย วาร์ป ของที่คุยได้)
tools/              สคริปต์ Python และชุดทดสอบ
```

## แก้เกมเอง

1. แก้ไฟล์ใน `data_src/` (เปิด CSV ด้วย Excel หรือ Google Sheets ได้)
2. รัน `python tools/build_data.py` — จะตรวจข้อผิดพลาดก่อน เช่น ท่าที่ไม่มีอยู่ แผนที่กว้างไม่เท่ากัน NPC ยืนทับต้นไม้
3. เปิดเกมใหม่

| อยากทำ | แก้ที่ |
| --- | --- |
| เปลี่ยนค่าพลัง เพิ่มผีสาง | `data_src/species.csv` |
| เพิ่ม/เปลี่ยนชื่อน้องวิศวะ | `data_src/eng_names.csv` (ชื่อห้ามซ้ำ) |
| เพิ่มท่า | `data_src/moves.csv` แล้วใส่ใน learnset ของตัวละคร |
| วาดแผนที่ใหม่ | `data_src/*.txt` (ความหมายตัวอักษรอยู่หัว `js/world.js`) |
| ย้าย NPC / ประตู / ป้าย / ตึกที่เข้าได้ | `data_src/world.json` |
| แก้บทพูด เหตุการณ์ | `js/story.js` |
| เปลี่ยนหน้าตาตัวละคร | `js/sprites.js` (`LOOKS` สำหรับคน `CUSTOM` สำหรับผี `SHOP` สีเสื้อช็อปและตรา `STAGE` ของประจำตัวเด็กขั้น 2–3) |

เครื่องมือ:

- `python tools/simulate.py 3000 15` — ให้เด็ก 4 คนสู้กันเองดูอัตราชนะ (เป้าหมาย 40–60%)
- `node tools/test_battle.js` — ทดสอบสูตรและระบบต่อสู้ 300 รอบ
- `python tools/pack.py` — รวมเป็นไฟล์ HTML เดียว + zip โปรเจกต์ใน `dist/`
